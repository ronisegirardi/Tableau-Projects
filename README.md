# Power BI Retail Sales Dashboard
### *Data Technician Bootcamp – Week 2 Portfolio Piece*

## Project Overview
A comprehensive interactive Power BI report built during my **Data Technician bootcamp**, transforming raw retail sales data into actionable business insights for stakeholders — from executive KPIs down to granular product and regional analysis.

## Key Skills & Techniques

### 1. Data Transformation & Cleaning — Power Query
- Connected to raw retail sales data and loaded it into Power BI
- Performed **ETL (Extract, Transform, Load)** in the Power Query Editor
- Removed duplicates, corrected data types, handled missing values, and filtered irrelevant rows
- Merged and appended tables to build a structured, analysis-ready model
- Established relationships between fact and dimension tables (star schema)

### 2. DAX — Calculated Columns & Measures
- Built calculated columns to enrich the data (e.g., product categories, customer segments)
- Created dynamic DAX measures for key metrics: Total Sales, Total Profit, Profit Margin %
- Used time intelligence functions (YTD, period-over-period comparisons) for trend analysis
- Made all measures responsive to user selections

### 3. Interactive Reporting — Slicers & Filters
- Added slicers for dynamic filtering by year, region, country, and product category
- Configured page-level and report-level filters to control the data narrative
- Built drill-through pages and cross-filtering between visuals
- Enabled users to explore data from business-wide to individual product/country level

### 4. Data Visualization — A Variety of Charts
| Visual | Purpose |
|--------|---------|
| **Bar Charts** | Compare sales & profit by category, country, and region |
| **Line Charts** | Track sales and profit trends over time |
| **Pie Charts** | Show revenue share by product category |
| **Filled Maps** | Visualize sales performance geographically |
| **KPI Cards** | Display headline metrics at a glance |

## Data Storytelling & Insights
The dashboard is structured as a guided narrative — from an executive overview, through sales trends, product and category analysis, to regional performance. Each visual answers a real business question: *Where are we performing well? Where are the gaps? What should we focus on next?*

## Tech Stack
- **Power BI Desktop** — report design and data modeling
- **Power Query** — data transformation and cleaning
- **DAX** — calculations and measures
- **Power BI Service** — publishing and sharing

## Key Takeaways
- Cleaning and preparing raw data for meaningful analysis
- Building an efficient, well-structured data model
- Using DAX to create flexible, dynamic metrics
- Designing user-friendly, interactive dashboards that communicate insights
- Telling a coherent data story that supports business decision-making

Completed as part of the **Data Technician bootcamp**, this project demonstrates the full analytics workflow — transforming raw retail and sales data into clear, interactive visualizations that support data-driven decisions.
