# GB Employment Dashboard
### *Data Technician Bootcamp*

## Project Overview
An interactive Tableau dashboard that analyses GB employment data, transforming raw employment records into clear, actionable insights for stakeholders. The report visualises how employment varies across regions, occupations and demographics, helping viewers quickly spot patterns and trends in the labour market.

**View the interactive dashboard:** [GB Employment Dataset on Tableau Public](https://public.tableau.com/app/profile/ronise.girardi/viz/GBEmploymentDataset_17846242219170/GBEmploymentData)

## Key Skills & Techniques

### 1. Interactive Dashboards
- Combined multiple worksheets into a single, cohesive dashboard
- Used containers and layout tools to organise visuals and guide the viewer's attention
- Designed a clean, user-friendly interface suitable for non-technical stakeholders
- Published and shared the dashboard via Tableau Public

### 2. Filters & Slicers
- Added interactive filters to let users explore the data dynamically
- Applied filters across the relevant worksheets so selections update the whole dashboard
- Used both categorical and context filters to control and refine what is displayed

### 3. Calculated Fields
- Created calculated fields to derive new metrics not present directly in the raw data
- Used calculations to enable comparisons and enrich the analysis
- Applied quick table calculations (e.g., percentage of total) to summarise contributions

### 4. Data Visualization — A Variety of Charts
| Visual | Purpose |
|--------|---------|
| **Bar Charts** | Compare employment levels across regions and occupational groups |
| **Line Charts** | Show employment trends over time and by gender |
| **Pie Charts** | Illustrate the distribution of employment across categories |
| **Maps** | Display employment geographically by region |

## Data Storytelling & Insights
The dashboard is structured to take the viewer from a high-level picture of the UK employment landscape down to specific regional and occupational insights. By combining maps, trend lines and distribution charts, it answers real questions about the labour market — *which regions have the highest employment, how has employment changed over time, and how does the workforce break down across categories?* — supporting data-driven decision-making.

## Tech Stack
- **Tableau Desktop** — data connection, worksheets and dashboard design
- **Tableau Public** — publishing and sharing the interactive dashboard
- **Calculated Fields & Filters** — dynamic metrics and user exploration

## Key Takeaways
- Building interactive, multi-sheet dashboards that communicate insights at a glance
- Using filters to make visuals responsive to user needs
- Creating calculated fields to add analytical depth to raw data
- Choosing the right chart type to tell a clear and compelling data story
